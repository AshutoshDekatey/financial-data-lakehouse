# v0.1 — deterministic settlement baseline

The smallest useful slice is two reproducible micro-batches and a full-history derived
projection. Source version wins over arrival order. Duplicate delivery cannot inflate
settlement, corrections replace prior values, late data updates older days, and invalid
or conflicting events are quarantined. Reruns are logically idempotent, though Delta
history still records overwrite commits.

Includes local Spark/Delta tests, a Databricks source notebook, synthetic input and
reconciliation. Uses AI-assisted implementation; validation claims are limited to the
recorded executed checks. No external cloud deployment was performed.

Future work: incremental downstream MERGE with affected-key aggregation, atomic
publication markers, per-currency reconciliation ledger, schema evolution and an actual
Databricks integration run. Applied AI is a career direction, not a feature claim in v0.1.
