# v0.1 — deterministic settlement baseline

The smallest useful slice is two reproducible micro-batches and a full-history derived
projection. Source version wins over arrival order. Duplicate delivery cannot inflate
settlement, corrections replace prior values, late data updates older days, and invalid
or conflicting events are quarantined. Reruns are logically idempotent, though Delta
history still records overwrite commits.

Includes local Spark/Delta tests, a Databricks source notebook, synthetic input and
reconciliation. Uses AI-assisted implementation; validation claims are limited to the
recorded executed checks. The project owner confirmed a successful real Databricks
notebook run with matching totals 12500 → 15000 → 15000 and two settled transactions
at each step; Gold settlement and quarantine tables were printed. This verifies the
supplied two-batch scenario and its in-notebook batch rerun. The three automated
tests remain local execution evidence. See [execution evidence](../evidence.md).

The Databricks runtime version, full exceptional-case suite on Databricks, concurrent
writers, scale performance, cross-table failure recovery and a second full notebook
execution remain unverified. No production deployment or benchmark is claimed.

Future work: incremental downstream MERGE with affected-key aggregation, atomic
publication markers, per-currency reconciliation ledger, schema evolution and broader
Databricks integration coverage. Applied AI is a career direction, not a feature claim in v0.1.
